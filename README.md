# Daily Payment Match Bot (ระบบตรวจสอบยอดเงินและจับคู่บิลอัตโนมัติ)

ระบบอัตโนมัติสำหรับดึงไฟล์ 2 ไฟล์จาก Google Drive ประจำวัน มาจับคู่ตรวจสอบความถูกต้องของยอดเงิน และส่งรายงานสรุปผลพร้อมไฟล์รายงานฉบับสมบูรณ์ (`match_result.xlsx`) เข้าทาง Telegram อัตโนมัติทุกวัน

---

## 📌 หลักการทำงานและการจับคู่ข้อมูล

ระบบจะค้นหาและดาวน์โหลดไฟล์ 2 ไฟล์จาก Google Drive โฟลเดอร์โดยอัตโนมัติ:
1. **ไฟล์ Report** (เช่น `Report_20261106_131614.xlsx`): ไฟล์รายงานการรับเงิน/แคชเชียร์ ซึ่งชื่อไฟล์จะเปลี่ยนไปตามวันและเวลา
2. **ไฟล์ Master** (เช่น `5-11.xls`, `6-11.xls`): ไฟล์สรุปบิลขายประจำวันจากระบบ Express/ERP ซึ่งชื่อไฟล์จะเปลี่ยนไปตามวันที่

### กฎการ Match ข้อมูล:
- **รหัสบิลขาย (PJ):** ดึงเลขที่บิลจากไฟล์ Report ในคอลัมน์ I (หมายเหตุ) หรือ คอลัมน์ B (หากระบุเป็น PJ) นำมาจับคู่กับ คอลัมน์ B (เลขที่เอกสาร) ในไฟล์ Master
- **การตรวจสอบยอดเงิน:** ตรวจสอบยอดเงินที่รับจริงในไฟล์ Report คอลัมน์ D (`ยอดเงิน`) เทียบกับ คอลัมน์ M (`มูลค่าสุทธิ`) ในไฟล์ Master
- **การจำแนกสถานะ:**
  - ✅ **ตรงกัน (Matched):** เลขที่บิลตรงกัน และ ยอดเงินตรงกันทุกบาท
  - ⚠️ **ยอดเงินไม่ตรงกัน (Mismatch):** เลขที่บิลตรงกัน แต่ยอดเงินใน Report ไม่ตรงกับ Master (แสดงผลต่างชัดเจน)
  - 🔍 **ไม่พบใน Master (Not Found):** มีการรับเงินใน Report แต่ไม่พบเลขที่บิลนี้ในไฟล์ Master
  - 📌 **Master ที่ไม่มีใน Report:** บิลขายใน Master ที่ยังไม่มีการบันทึกชำระเงินใน Report

---

## 📊 รายละเอียดไฟล์รายงาน `match_result.xlsx`

ไฟล์สรุปผลจะแบ่งออกเป็น 5 หน้าชีตอย่างชัดเจน:
1. **`สรุปภาพรวม`**: สรุปยอดรวม รายการที่ตรง ไม่ตรง ผลรวมความถูกต้อง และเวลาประมวลผล
2. **`ข้อมูลตรงกัน`**: รายการที่จับคู่สำเร็จพร้อมยอดเงินที่ตรงกัน
3. **`ยอดเงินไม่ตรงกัน`**: รายการที่มีผลต่าง แสดงยอด Report, ยอด Master, ผลต่าง และชื่อลูกค้า
4. **`ไม่พบใน Master`**: รายการที่มีการรับเงินใน Report แต่ไม่พบบิลใน Master
5. **`Master ไม่มีใน Report`**: รายการบิลขายที่ยังไม่พบยอดเงินใน Report

## ⚙️ วิธีติดตั้งและตั้งค่าบน GitHub Actions (ตั้งเวลาทำงานทุกวัน)

1. นำโค้ดขึ้น GitHub Repository
2. ไปที่ **Settings** > **Secrets and variables** > **Actions** > กด **New repository secret**
3. เพิ่มตัวแปร Secrets ดังนี้:
   - `TELEGRAM_TOKEN`: Bot Token ที่ได้จาก `@BotFather`
   - `TELEGRAM_CHAT_ID`: Chat ID หรือ Group ID ที่ต้องการให้บอทส่งข้อความแจ้งเตือน
   - *(ทางเลือก)* `GDRIVE_FOLDER_URL`: ลิงก์ Google Drive Folder (หากไม่ใส่จะใช้โฟลเดอร์เริ่มต้นที่ตั้งไว้ในระบบ)

### การทำงานอัตโนมัติ:
- ระบบถูกตั้งเวลาให้ทำงานอัตโนมัติทุกวันเวลา **08:00 น.** ตามเวลาประเทศไทย ผ่าน [`.github/workflows/daily_match.yml`](.github/workflows/daily_match.yml)
- สามารถกดปุ่ม **Run workflow** ในแท็บ **Actions** บน GitHub เพื่อสั่งรันประมวลผลแบบทันที (Manual) ได้ตลอดเวลา
- ไฟล์ `match_result.xlsx` จะถูกส่งเข้า Telegram ทันที และถูกเก็บไว้เป็น Artifact บน GitHub Actions นาน 30 วัน
