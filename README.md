# Daily Payment Match Bot - น้องบิ๊นท์ (ระบบตรวจสอบยอดเงินและจับคู่บิลอัตโนมัติ)

ระบบอัตโนมัติของ **น้องบิ๊นท์** สำหรับดึงไฟล์ 2 ฝั่งจาก Google Drive ประจำวัน มาจับคู่ตรวจสอบความถูกต้องของยอดเงิน (PJ และ V) และส่งรายงานสรุปผลพร้อมไฟล์ Excel (`match_result.xlsx`) เข้าทาง Telegram อัตโนมัติทุกวัน

---

## 📌 หลักการทำงานและการจับคู่ข้อมูล

ระบบจะค้นหาและดาวน์โหลดไฟล์ 2 ฝั่งจาก Google Drive โฟลเดอร์โดยอัตโนมัติ:
1. **ไฟล์ Report** (เช่น `Report_20261109_081730.xlsx`): ไฟล์รายงานการรับเงิน/แคชเชียร์
2. **ไฟล์ Master** (เช่น `5-11.xls`, `6-11.xls`, `8-11.xls`): ไฟล์สรุปบิลขายประจำวันจากระบบ Express/ERP

### กฎการ Match ข้อมูลของน้องบิ๊นท์:
- **กลุ่ม PJ (รวม *PJ):** หมายเหตุใน Report ที่เป็นตัวเลขล้วน หรือระบุ PJ จะจับคู่เฉพาะกลุ่ม PJ ใน Master เท่านั้น (ไม่จับคู่ข้ามกับ V)
- **กลุ่ม V (ใบกำกับภาษี):** หมายเหตุใน Report ที่มีเครื่องหมาย `/` หรือมีตัวอักษร V จะจับคู่เฉพาะกลุ่ม V ใน Master เท่านั้น
- **เอกสารยกเลิก (*V):** นำมาแสดงในรายงานให้ครบถ้วนทุกแถว (เช่น แสดงในชีต Master ที่ไม่มีใน Report) แต่ไม่นำมาจับคู่กับยอดเงินที่รับมา
- **การตรวจสอบยอดเงิน:** ตรวจสอบยอดเงินจริงใน Report คอลัมน์ D (`ยอดเงิน`) เทียบกับ คอลัมน์ M (`มูลค่าสุทธิ`) ใน Master

## 📱 คำสั่งใช้งานผ่าน Telegram Bot (คุยกับน้องบิ๊นท์)

คุณสามารถส่งข้อความหาน้องบิ๊นท์ใน Telegram ได้โดยตรงด้วยคำสั่งภาษาไทย:
1. **`ตรวจสอบไฟล์`** ➔ ให้น้องบิ๊นท์ตรวจสอบโฟลเดอร์ Google Drive แล้วสรุปรายงานสถานะว่ามีไฟล์ของวันไหนบ้าง ระบบไหนส่งไฟล์มาแล้วบ้าง และวันไหนพร้อมจับคู่แล้ว
2. **`จับคู่เอกสาร`** ➔ สั่งให้น้องบิ๊นท์จับคู่ข้อมูลและส่งรายงาน Excel ของวันล่าสุดที่พร้อมทันที
3. **`จับคู่เอกสาร [วันที่]`** (เช่น `จับคู่เอกสาร 05/11` หรือ `จับคู่เอกสาร 06-08/11`) ➔ ระบุวันที่ที่ต้องการจับคู่เจาะจงได้
